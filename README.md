# Busqueda-BFS-vs-A-con-Heuristica-Manhattan
Un robot autonomo debe localizar a una victima en un edificio colapsado modelado como un laberinto de 5×5 celdas. Cada celda puede estar libre (·), contener un obstaculo  (x), o la victima (V). El agente parte desde la esquina superior izquierda y puede moverse en las cuatro direcciones siempre que la celda este libre.
